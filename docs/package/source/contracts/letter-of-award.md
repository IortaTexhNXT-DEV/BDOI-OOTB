# About this template

> Template for discussion; subject to review by the parties' legal counsel.

The client uses one of these two documents to confirm its choice of iNXT BrokerVerse OOTB before the contract set is signed:

- the **Letter of Award**, on the client's letterhead, when the client has run a selection or tender;
- the **Proposal Acceptance** form, when the client accepts an iorta TechNXT proposal directly.

Both record the selected package and price, authorise iorta TechNXT to prepare the contract set and, if chosen, to start mobilisation. Neither replaces the Master Services Agreement and the Order Form. Text in [square brackets] is a placeholder or an option.
