# docs/package

This folder held the generic BrokerVerse OOTB documentation pack (sales, commercials, contracts, onboarding,
delivery, support, technical and management documents for any Philippine non-life broker). The documents that do
not apply to TISPH, or that the TISPH document pack replaces, have been removed or archived. The TISPH documents
and the Document Register are indexed in [`docs/TISPH/README.md`](../TISPH/README.md); archived files are listed in
[`docs/archive/2026-10-10/README.md`](../archive/2026-10-10/README.md).

What stays here, and why. Product documents can still be found on the BrokerVerse product line.

| File or folder | Why it stays |
|---|---|
| `05_Delivery/Upload_Templates/` | Generated by `backend/scripts/build-upload-templates.js`; served by the template downloads; cited by the TISPH data migration plan |
| `04_Onboarding_and_Go_Live/Brand_Packs/` | Input of `backend/scripts/build-brand-pack.js` and the bundled brand packs (`backend/src/modules/branding/bundled.js`) |
| `source/user-manual.md`, `source/manual-images/`, `05_Delivery/BrokerVerse_User_Manual.docx` / `.pdf` | Source of the product (base) edition of the in-app Help (`brokerverse/scripts/build-help.js`, `npm run help:build -- --edition base --out <folder>`); the TISPH edition is built from `docs/TISPH/manual/` |
| `07_Technical/BrokerVerse_Data_Dictionary.xlsx`, `source/data-dictionary.md`, `tools/data-dictionary/` | Personal data catalogue of the masking tool (`backend/scripts/lib/pii-catalogue.js`, `backend/test/mask-data.test.js`) |
| `06_Support/BrokerVerse_Release_Notes_Template.*`, `source/release-notes-template.md` | Release notes template (production readiness item B-07) |
| `04_Onboarding_and_Go_Live/BrokerVerse_Privacy_Impact_Assessment_and_Records_of_Processing_Templates.*`, `source/privacy-impact-assessment-templates.md` | Template for the TISPH Data Protection Officer |
| `03_Contracts/` (support agreement and SLA, customer responsibilities and RACI annex, change request procedure and form, source code escrow agreement, exit and transition plan, hypercare exit and handover certificate) and their sources in `source/contracts/` | Product templates cited by the TISPH operations and governance documents until the TISPH versions exist |
| `04_Onboarding_and_Go_Live/BrokerVerse_Security_Due_Diligence_Questionnaire.*` | Kept until TISPH Information Security decides whether it wants the questionnaire in this form |
| `05_Delivery/` process flows, regulatory compliance matrix, reports book, communication templates and touchpoints, schedules and batch jobs, training plan, project status report and RAID log templates | Kept until their TISPH replacements exist (FRS for the remaining build items, report inventory, compliance decision) or while the TISPH documents cite them |
| `06_Support/` production support approach, business continuity and disaster recovery plan | Templates to tailor for TISPH support (operations planned item P29) |
| `tools/` | Builders of the files above: `python3 tools/build_all.py --list` shows which source becomes which file |
