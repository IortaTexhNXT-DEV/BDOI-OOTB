# docs/package

This folder held the generic BrokerVerse OOTB documentation pack. The documents that do not apply to TISPH, or that
the TISPH document pack replaces, have been removed or archived (cleanup of 10 and 11 October 2026, recorded in
`docs/TISPH/pack/TISPH_Documentation_Cleanup.docx`). The TISPH documents and the Document Register are indexed in
[`docs/TISPH/README.md`](../TISPH/README.md). The archive, the contract templates, the old user manuals and the
past test-run evidence were removed on 12 October 2026; they remain in the git history.

What stays here, and why:

| File or folder | Why it stays |
|---|---|
| `05_Delivery/Upload_Templates/` | Generated by `backend/scripts/build-upload-templates.js`; served by the template downloads; cited by the TISPH data migration plan |
| `04_Onboarding_and_Go_Live/Brand_Packs/` | Input of `backend/scripts/build-brand-pack.js` and the bundled brand packs (`backend/src/modules/branding/bundled.js`); TISPH uses `toyota-insurance-services` |
| `source/user-manual.md`, `source/manual-images/` | Source of the base edition of the in-app Help (`brokerverse/scripts/build-help.js`); the TISPH edition that this branch ships is built from `docs/TISPH/manual/` |
| `07_Technical/BrokerVerse_Data_Dictionary.xlsx`, `source/data-dictionary.md`, `tools/data-dictionary/` | Personal data catalogue of the masking tool (`backend/scripts/lib/pii-catalogue.js`, `backend/test/mask-data.test.js`) |
| `06_Support/BrokerVerse_Release_Notes_Template.*`, `source/release-notes-template.md` | Release notes template (production readiness item B-07) |
| `04_Onboarding_and_Go_Live/BrokerVerse_Privacy_Impact_Assessment_and_Records_of_Processing_Templates.*`, `source/privacy-impact-assessment-templates.md` | Template for the TISPH Data Protection Officer (Document Register DR-39) |
| `tools/` | Builders of the files above: `python3 tools/build_all.py --list` shows which source becomes which file |
